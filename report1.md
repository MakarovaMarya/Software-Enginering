# Общий вывод по теме
Git используется для контроля версий разрабатываемых проектов, командной работы и обеспечения безопасности проектов. По сути, git можно использовать как "машину времени" для кода - можно вернутся к предыдущим версиям проекта в любой момент времени. При этом в git можно работать параллельно над несколькими проектами и создавать их резервные копии.
